# 📖 Guides

> How-tos, tutoriales paso a paso, procedimientos operativos.

## ¿Qué va aquí?

Documentos con la forma **"para hacer X, sigue estos pasos"**. Ejemplos:

- Cómo desplegar las Lambdas con SAM
- Cómo rotar el secret del JWT
- Cómo añadir un nuevo endpoint al backend
- Cómo crear una migración de DB

## Plantilla

Usa [`../templates/how-to.md`](../templates/how-to.md) como punto de
partida. Estructura mínima:

```markdown
# Título del how-to

> **Audiencia**: backend-devs, devops
> **Tiempo estimado**: 10 min

## Prerrequisitos

- ...

## Pasos

1. ...
2. ...

## Troubleshooting

- **Problema X**: Solución Y

## Referencias

- ...
```
